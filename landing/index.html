The markup

The whole API is an anchor

Two attributes are required and the rest are polish. Turn JavaScript off and the link goes back to being a link — nothing breaks.

<!-- an href, a group name, and that's the lot -->
<a href="/media/drawing.pdf"
   data-filedeck="files"
   data-size="640 KB · 12 pages"
   title="drawing-rev-c.pdf">
  Assembly drawing
</a>

<script src="filedeck.umd.min.js"></script>
<script>new Filedeck();</script>
data-filedeck required
The group name. Everything sharing it pages through together, arrows and filmstrip included.
title
The filename in the header. Skip it and the alt text stands in, then the URL.
data-width  data-height
Pass the dimensions and the layout lands on the first frame instead of settling into place.
data-thumb
Point the filmstrip at something small so it stops dragging full-size images around. Otherwise it falls back to the nested <img>, then a file-type icon.
data-name  data-caption  data-meta
Filename, caption and a subtitle line. Names resolve data-name → title → img alt → basename.
data-kind
For URLs with no extension — a permission-checked /download/ view, say. Pick from image, pdf, video, audio, file.
Formats

Yes, even the .dwg

Every file gets a sensible landing. Controls that make no sense for a format quietly don't appear — no greyed-out buttons pretending to be useful.

IMG

Pictures

Zoom to 400%, pan around, pinch on a phone. jpg png gif webp avif svg

PDF

Paperwork

The browser's own PDF reader, embedded full-stage. Small screens get a tidy card instead.

A/V

Sound and motion

Native players, so scrubbing stays scrubbing. mp4 webm mp3 wav

XLS

The awkward ones

Spreadsheets, documents, CAD: no preview for these yet — you get a labelled file card with the size and a download button.

Controls

Fingers, keys, or code

The swipe axis locks after about 12px, so a wonky diagonal does one thing instead of two. A fast flick counts even if you barely moved.

Install

Pick your poison

CDN and a script tag if you like living simply. Self-host the two files if you'd rather. npm if you already own a bundler and want to keep it busy.

Script tag

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/filedeck@0.1/dist/filedeck.min.css">
<script src="https://cdn.jsdelivr.net/npm/filedeck@0.1/dist/filedeck.umd.min.js"></script>

npm

npm install filedeck

// then
import Filedeck from 'filedeck';
import 'filedeck/filedeck.css';

new Filedeck();

Thirty seconds. Then never think about attachments again.
